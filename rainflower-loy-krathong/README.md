# ลอยกระทงออนไลน์กับ Rainflower

เว็บลอยกระทงที่มี backend เก็บ **จำนวนกระทงทั้งหมด** และให้ผู้ใช้ที่เปิดเว็บอยู่ในเวลาเดียวกัน
**เห็นกระทง ชื่อ และคำอวยพรของกันและกันแบบเรียลไทม์**

ไม่ต้องติดตั้งแพ็กเกจเพิ่ม (ไม่ต้อง `npm install`) ใช้แค่ Node.js 18 ขึ้นไป

## วิธีรัน

```bash
node server.js
# เปิด http://localhost:3000
```

ตั้งค่าได้ผ่าน environment variable

| ตัวแปร | ค่าเริ่มต้น | ความหมาย |
|---|---|---|
| `PORT` | `3000` | พอร์ต |
| `HOST` | `0.0.0.0` | ที่อยู่ที่ฟัง |
| `DATA_DIR` | `./data` | โฟลเดอร์เก็บข้อมูล (`krathong.json`) |
| `TRUST_PROXY` | ไม่ตั้ง | ตั้งเป็น `1` เมื่ออยู่หลัง nginx/Cloudflare เพื่อใช้ IP จริงในการจำกัดความถี่ |

## โครงสร้าง

```
server.js        เซิร์ฟเวอร์ (API + เรียลไทม์ + เสิร์ฟหน้าเว็บ)
public/index.html หน้าเว็บ
data/krathong.json  ข้อมูล (สร้างอัตโนมัติ: จำนวนรวม + กระทงล่าสุด 200 อัน)
```

## API

| Method | Path | หน้าที่ |
|---|---|---|
| `POST` | `/api/float` | ลอยกระทง body: `{"t":0-4,"n":"ชื่อ ≤20 ตัว","w":"คำอวยพร ≤80 ตัว","id":"(ไม่บังคับ)"}` |
| `GET` | `/api/stream` | Server-Sent Events: `hello` (จำนวนรวม, คนออนไลน์, กระทงที่เพิ่งลอย), `float` (กระทงใหม่), `online` |
| `GET` | `/api/stats` | `{"total":123,"online":4}` |

## พฤติกรรมที่ควรรู้

- ผู้ที่เพิ่งเปิดเว็บจะเห็นกระทงของคนอื่นที่เพิ่งลอยไปไม่เกิน 90 วินาทีที่ผ่านมา กำลังลอยอยู่กลางทาง
- จำกัดการลอยไม่เกิน 4 ครั้งต่อ 10 วินาทีต่อ IP และตัดอักขระควบคุม/ช่องว่างซ้ำออกจากชื่อและคำอวยพร
- ข้อมูลถูกบันทึกลงไฟล์ทุก ~1 วินาทีหลังมีกระทงใหม่ และบันทึกอีกครั้งตอนปิดเซิร์ฟเวอร์ (Ctrl+C)
- ถ้าเปิด `public/index.html` ตรงๆ โดยไม่ผ่านเซิร์ฟเวอร์ จะทำงานแบบออฟไลน์ (เห็นเฉพาะกระทงของตัวเอง)
- หลัง nginx ให้ปิด buffering ของ `/api/stream` (เซิร์ฟเวอร์ส่งหัว `X-Accel-Buffering: no` ให้แล้ว)
- ถ้ารันหลายโปรเซส/หลายเครื่อง ข้อมูลและเรียลไทม์จะไม่ถูกแชร์ข้ามกัน ให้รันโปรเซสเดียว
  หรือเปลี่ยนที่เก็บข้อมูลเป็น Redis/ฐานข้อมูลภายหลัง
